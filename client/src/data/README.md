# data/

All content lives here — no need to touch components.

- `config.ts`  – button labels, video path
- `playlist.ts` – background songs (title, artist, file)
- `letters.ts` – your letter and dad's letter (one entry per page)
- `stages.ts`  – life-stage groups used by the timeline
- `photos.ts`  – one row per photo: image path, year, stage, message

Media goes in `client/public/media/{photos,audio,video}/`.
